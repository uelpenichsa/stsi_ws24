# Wordle Spielanleitung von Justin

1. Um Spiel zu starten bitte folgenden Comand ausführen:2

```
./wordle.sh
```

2. Falls Sie eher so mittel in Wordle sind, können Sie sich auch unlimitierte Versuche einstellen:

```
./wordle.sh unlimit
```
